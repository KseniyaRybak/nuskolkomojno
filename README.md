# Новый рабочий дашборд

Этот вариант сделан полностью заново и максимально просто:

- только один файл `index.html`;
- данные уже встроены внутрь страницы;
- нет CSV, Parquet, дополнительных JS-файлов и внешних библиотек;
- подходит для GitHub Pages без дополнительных настроек.

## Как загрузить

1. Открой репозиторий на GitHub.
2. Удали старые файлы проекта, если хочешь полностью заменить старый дашборд.
3. Нажми `Add file` -> `Upload files`.
4. Загрузи `index.html`.
5. Нажми `Commit changes`.
6. Открой опубликованный GitHub Pages сайт и обнови страницу.

## Что должно быть в репозитории

Минимальный рабочий вариант:

```text
index.html
```

Можно оставить README, но для сайта он не нужен.
